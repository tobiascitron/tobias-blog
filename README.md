# tobias-blog

Plain HTML/CSS personal blog. No build step.

## Add a new post

1. Copy `posts/hello-world.html` to `posts/your-slug.html`
2. Edit the title, date, and content
3. Add a new `<li>` entry at the top of the list in `index.html`

## Deploy

Push to GitHub, then import the repo on [vercel.com](https://vercel.com) — no config needed, it's a static site.
